MPIcon ​

아이콘 글리프에 크기와 색을 붙여 주는 wrapper입니다. Material Plus는 자체 아이콘을 그리지 않으므로 글리프는 여러분이 고른 세트에서 옵니다. React 패키지에는 lucide-react가 함께 들어 있고, 다른 세트도 똑같이 잘 동작합니다.

ReactFlutter
tsx
import { MPIcon, ICONS } from 'material-plus-ui';

<MPIcon icon={ICONS.success} size={24} color="green" label="배포됨" />;
dart
import 'package:material_plus_ui/material_plus_ui.dart';

const MPIcon(icon: SuccessGlyph(), size: 24, color: Color(0xFF2E7D32), label: '배포됨');

Props ​

Prop타입기본값설명
icon * MPIconGlyph—그릴 글리프. 아이콘 세트의 컴포넌트(`ICONS.search`)이거나 직접 만든 엘리먼트(`<svg>…</svg>`)입니다
sizenumber | string—글리프가 그려지는 박스. 숫자는 CSS 픽셀, 문자열은 임의의 CSS 길이입니다. 지정하지 않으면 글리프 자신의 크기로 그려집니다
colorstring—임의의 CSS 색상. 지정하지 않으면 아이콘이 놓인 자리의 색을 그대로 물려받습니다
strokeWidthnumber | string—선 두께. 컴포넌트로 넘긴 글리프에만 전달되며, 이미 그려진 엘리먼트는 무시합니다
centerbooleanfalse그리드나 flex 트랙 안에서 아이콘을 가운데로 보냅니다
labelstring—아이콘이 전달하는 의미. 지정하면 `role="img"`으로 읽히고, 지정하지 않으면 접근성 트리에서 완전히 빠집니다
classNamestring—컴포넌트가 그리는 가장 바깥 엘리먼트에, 컴포넌트 자신의 클래스 뒤에 붙습니다. 병합이 아니라 이어 붙이기입니다 — 같은 속성을 지정하는 두 유틸리티가 어떻게 결정되는지는 시작하기 가이드의 `클래스와 스타일`을 보세요
styleReact.CSSProperties—같은 엘리먼트에 붙는 인라인 스타일이며, 컴포넌트가 거기에 지정해 둔 것 위에 덮입니다. 인라인은 어떤 스타일시트보다 우선하므로, 인스턴스 하나에만 토큰을 넘기는 길입니다
Prop타입기본값설명
icon * IconData | Widget—그릴 글리프. 아이콘 폰트의 `IconData`나 직접 만든 위젯을 받습니다. Dart에는 유니언 타입이 없어 `Object`로 받고, 둘 다 아니면 디버그에서 assert로 막습니다
sizedouble?—글리프를 그리는 상자의 크기(논리 픽셀). 비워 두면 주변 `IconTheme`의 크기를 따르고, 아무것도 없으면 24입니다
colorColor?—글리프의 색. 비워 두면 놓인 자리의 색(`IconTheme`, `DefaultTextStyle`)을 이어받습니다
labelString?—아이콘이 전달하는 의미. 지정하면 `role="img"`으로 읽히고, 지정하지 않으면 접근성 트리에서 완전히 빠집니다

<span>의 native 속성은 그대로 전달되고, ref는 박스에 닿습니다.

글리프는 children이 아니라 prop입니다 ​

tsx
<MPIcon icon={ICONS.search} />       // ✅
<MPIcon>{<SearchIcon />}</MPIcon>    // ✗ — children prop은 없습니다
dart
MPIcon(icon: mySet.search)           // IconData
const MPIcon(icon: SearchGlyph())    // 위젯

아이콘에 대해 늘 정하고 싶은 두 가지 — 얼마나 큰지, 무슨 색인지 — 는 그것이 무언가의 자식이 되고 나면 손댈 수 없는 두 가지이기 때문입니다. prop으로 받으면 MPIcon이 단순히 감싸는 내용이 아니라 크기를 정하는 내용이 됩니다.

icon ​

아이콘 세트가 돌려주는 형태가 두 가지이므로, 두 형태 모두 받습니다.

ReactFlutter
tsx
import { MPIcon } from 'material-plus-ui';
import type { MPIconGlyphProps } from 'material-plus-ui';

/** A drawing of your own, as a component: it is handed the size and the colour. */
function SpiralIcon({ size, color, strokeWidth }: MPIconGlyphProps) {
  return (
    <svg viewBox="0 0 24 24" width={size} height={size} fill="none">
      <path
        d="M12 3a9 9 0 1 1-9 9 7 7 0 0 1 7-7 5 5 0 0 1 5 5 3 3 0 0 1-3 3"
        stroke={color}
        strokeWidth={strokeWidth ?? 1.6}
        strokeLinecap="round"
      />
    </svg>
  );
}

export default function IconCustom() {
  return (
    <div
      className="text-mp-on-surface"
      style={{ display: 'flex', gap: 32, alignItems: 'center', flexWrap: 'wrap' }}
    >
      <div style={{ display: 'grid', gap: 8, justifyItems: 'center' }}>
        <MPIcon icon={SpiralIcon} size={28} label="Spiral" />
        <small className="text-mp-on-surface-variant">component</small>
      </div>

      <div style={{ display: 'grid', gap: 8, justifyItems: 'center' }}>
        {/* Already drawn, so nothing is passed into it — the box scales it. */}
        <MPIcon
          icon={
            <svg viewBox="0 0 24 24" fill="none">
              <rect
                x="4"
                y="4"
                width="16"
                height="16"
                rx="4"
                stroke="currentColor"
                strokeWidth="1.6"
              />
              <path
                d="M9 12h6M12 9v6"
                stroke="currentColor"
                strokeWidth="1.6"
                strokeLinecap="round"
              />
            </svg>

dart
import 'package:flutter/widgets.dart';
import 'package:material_plus_ui/material_plus_ui.dart';

/// A drawing of your own that reads its size and colour off the [IconTheme],
/// the way an icon set's widget does: it is handed both.
class _SpiralGlyph extends StatelessWidget {
  const _SpiralGlyph();

  @override
  Widget build(BuildContext context) {
    final IconThemeData theme = IconTheme.of(context);

    return CustomPaint(
      size: Size.square(theme.size ?? 24),
      painter: _SpiralPainter(theme.color ?? const Color(0xFF000000)),
    );
  }
}

class _SpiralPainter extends CustomPainter {
  const _SpiralPainter(this.color);

  final Color color;

  @override
  void paint(Canvas canvas, Size size) {
    canvas
      ..save()
      ..scale(size.shortestSide / 24)
      ..drawPath(
        Path()
          ..moveTo(12, 3)
          ..arcToPoint(const Offset(3, 12), radius: const Radius.circular(9), largeArc: true)
          ..arcToPoint(const Offset(10, 5), radius: const Radius.circular(7))
          ..arcToPoint(const Offset(15, 10), radius: const Radius.circular(5))
          ..arcToPoint(const Offset(12, 13), radius: const Radius.circular(3)),
        Paint()
          ..style = PaintingStyle.stroke
          ..strokeWidth = 1.6
          ..strokeCap = StrokeCap.round
          ..color = color,
      )
      ..restore();
  }

  @override
  bool shouldRepaint(_SpiralPainter oldDelegate) => oldDelegate.color != color;
}

/// A drawing that is already drawn: a fixed 24-unit picture that reads
/// nothing, so the box scales it.
class _AddMark extends StatelessWidget {
  const _AddMark();

  @override
  Widget build(BuildContext context) {
    // The colour is taken once, here, the way an SVG's `currentColor` is; the
    // size is not taken at all.
    final Color color = DefaultTextStyle.of(context).style.color ?? const Color(0xFF000000);

    return FittedBox(
      child: CustomPaint(size: const Size.square(24), painter: _AddPainter(color)),
    );
  }
}

class _AddPainter extends CustomPainter {
  const _AddPainter(this.color);

  final Color color;

  @override
  void paint(Canvas canvas, Size size) {
    final Paint stroke = Paint()
      ..style = PaintingStyle.stroke
      ..strokeWidth = 1.6
      ..strokeCap = StrokeCap.round
      ..color = color;

    canvas
      ..drawRRect(
        RRect.fromRectAndRadius(const Rect.fromLTWH(4, 4, 16, 16), const Radius.circular(4)),
        stroke,
      )
      ..drawLine(const Offset(9, 12), const Offset(15, 12), stroke)
      ..drawLine(const Offset(12, 9), const Offset(12, 15), stroke);
  }

  @override
  bool shouldRepaint(_AddPainter oldDelegate) => oldDelegate.color != color;
}

class IconCustom extends StatelessWidget {
  const IconCustom({super.key});

  @override
  Widget build(BuildContext context) {
    final MPThemeData theme = MPTheme.of(context);
    final TextStyle caption = theme.typescale.bodySmall.style(theme.colors.onSurfaceVariant);

    return DefaultTextStyle.merge(
      style: TextStyle(color: theme.colors.onSurface),
      child: IconTheme.merge(
        data: IconThemeData(color: theme.colors.onSurface),
        child: Wrap(
          spacing: 32,
          runSpacing: 24,
          crossAxisAlignment: WrapCrossAlignment.center,
          children: <Widget>[
            Column(
              mainAxisSize: MainAxisSize.min,
              spacing: 8,
              children: <Widget>[
                const MPIcon(icon: _SpiralGlyph(), size: 28, label: 'Spiral'),
                Text('component', style: caption),
              ],
            ),
            Column(
              mainAxisSize: MainAxisSize.min,
              spacing: 8,
              children: <Widget>[
                // Already drawn, so nothing is passed into it: the box scales it.
                const MPIcon(icon: _AddMark(), size: 28, label: 'Add'),
                Text('element', style: caption),
              ],
            ),
          ],
        ),
      ),
    );
  }
}

컴포넌트는 lucide-react, react-icons 등 대부분의 세트가 export하는 형태이고, MPIcon이 크기와 색을 글리프 안으로 넘길 수 있게 해 주는 형태입니다. 바깥에서 엘리먼트에 스타일을 입히려 애쓸 필요가 없습니다.

tsx
<MPIcon icon={ICONS.close} size={20} />

엘리먼트는 직접 그린 그림, 다른 세트에서 이미 만들어진 글리프, <img> 같은 것입니다. 놓인 박스에 맞춰 크기가 조정됩니다.

tsx
<MPIcon icon={<svg viewBox="0 0 24 24">…</svg>} size={20} />
<MPIcon icon={<DeleteIcon />} size={20} />

구분은 오직 React.isValidElement로만 합니다. 그래서 요즘 아이콘 세트가 실제로 export하는 forwardRef 객체가 "이미 그려진 것"이 아니라 컴포넌트로 올바르게 취급됩니다.

**IconData**는 아이콘 폰트가 돌려주는 형태입니다. MPIcon이 받은 크기와 색으로 Icon을 그립니다.

dart
MPIcon(icon: mySet.close, size: 20)

위젯은 직접 그린 그림, 패키지에서 가져온 SVG, 다른 세트가 만든 글리프입니다. 크기와 색을 IconTheme, DefaultTextStyle, 놓이는 박스 세 갈래로 한꺼번에 알려 주므로, IconTheme.of(context)를 읽는 그림이든 박스를 채우는 위젯이든 글자 하나든 같은 크기로 나옵니다.

dart
const MPIcon(icon: SpiralGlyph(), size: 20)
MPIcon(icon: SvgPicture.asset('assets/delete.svg'), size: 20)

Dart에는 유니언 타입이 없어 icon은 Object로 받습니다. IconData도 Widget도 아니면 디버그에서 assert로 막습니다.

size ​

숫자는 CSS 픽셀, 문자열은 임의의 CSS 길이입니다. size="1em"으로 주변 텍스트를 따라가게 할 수 있습니다.

논리 픽셀 단위의 숫자입니다. 주변 텍스트를 따라가게 하려면 그 크기를 읽어서 넘깁니다. size: DefaultTextStyle.of(context).style.fontSize처럼 씁니다.

ReactFlutter
tsx
import { MPIcon, ICONS } from 'material-plus-ui';

const SIZES = [14, 16, 20, 24, 32];

export default function IconSizes() {
  return (
    <div style={{ display: 'flex', gap: 32, alignItems: 'flex-end', flexWrap: 'wrap' }}>
      {SIZES.map((size) => (
        <div
          key={size}
          style={{ display: 'grid', gap: 8, justifyItems: 'center' }}
          className="text-mp-on-surface"
        >
          <MPIcon icon={ICONS.info} size={size} label={`Info, ${size}px`} />
          <small className="text-mp-on-surface-variant">{size}</small>
        </div>
      ))}
    </div>
  );
}
dart
import 'package:flutter/widgets.dart';
import 'package:material_plus_ui/material_plus_ui.dart';

import 'package:material_plus_ui_example/demos/glyphs_display.dart';

class IconSizes extends StatelessWidget {
  const IconSizes({super.key});

  static const List<double> _sizes = <double>[14, 16, 20, 24, 32];

  @override
  Widget build(BuildContext context) {
    final MPThemeData theme = MPTheme.of(context);

    return IconTheme.merge(
      data: IconThemeData(color: theme.colors.onSurface),
      child: Wrap(
        spacing: 32,
        runSpacing: 24,
        crossAxisAlignment: WrapCrossAlignment.end,
        children: <Widget>[
          for (final double size in _sizes)
            Column(
              mainAxisSize: MainAxisSize.min,
              spacing: 8,
              children: <Widget>[
                MPIcon(icon: const InfoGlyph(), size: size, label: 'Info, ${size.round()}px'),
                Text(
                  '${size.round()}',
                  style: theme.typescale.bodySmall.style(theme.colors.onSurfaceVariant),
                ),
              ],
            ),
        ],
      ),
    );
  }
}

크기 사다리(sm/md/lg)는 없습니다. 아이콘 세트는 특정 크기의 픽셀 격자 위에 그려지는데, wrapper가 자기만의 다섯 단계를 만들어 내는 것은 세트가 이미 내린 결정에 대한 두 번째 의견일 뿐입니다. 지정하지 않으면 글리프가 만들어진 크기 그대로 그려집니다.

길이는 박스에도 쓰이고 박스의 font-size에도 쓰입니다. width를 직접 들고 있는 <svg>와 em으로 그려진 <svg>가 같은 크기로 나오는 이유입니다.

Flutter에서 "만들어진 크기"는 주변 IconTheme의 크기입니다. 아무것도 없으면 24이고, 버튼 안이라면 이미 버튼이 맞춰 둔 크기입니다.

color ​

React에서는 임의의 CSS 색상, Flutter에서는 Color입니다. 지정하지 않으면 아이콘이 놓인 자리의 색을 그대로 물려받는데, 자기만의 색을 갖는 것보다 이쪽이 맞는 경우가 훨씬 많습니다. 버튼 라벨, 흐린 캡션, Alert 안의 아이콘은 그 요소의 색이어야 합니다.

ReactFlutter
tsx
import { MPIcon, ICONS } from 'material-plus-ui';

export default function IconColors() {
  return (
    <div style={{ display: 'grid', gap: 24 }}>
      {/* A colour named outright. Any CSS colour works — including one of the
          library's own role tokens, which is what keeps it right in both
          schemes without the demo knowing which one it is in. */}
      <div style={{ display: 'flex', gap: 24, alignItems: 'center', flexWrap: 'wrap' }}>
        <MPIcon icon={ICONS.info} size={24} color="var(--color-mp-primary)" label="Info" />
        <MPIcon icon={ICONS.error} size={24} color="var(--color-mp-error)" label="Failed" />
        <MPIcon
          icon={ICONS.warning}
          size={24}
          color="var(--color-mp-on-surface-variant)"
          label="Careful"
        />
        <MPIcon icon={ICONS.success} size={24} color="#2e7d32" label="Done" />
      </div>

      {/* No colour at all. The icon takes whatever the surrounding text is,
          which is why both of these come out right without being told. */}
      <div style={{ display: 'grid', gap: 12 }}>
        <p className="text-mp-body-small text-mp-error" style={{ display: 'flex', gap: 8 }}>
          <MPIcon icon={ICONS.warning} size="1.2em" />
          This certificate expires in three days.
        </p>
        <p
          className="text-mp-body-small text-mp-on-surface-variant"
          style={{ display: 'flex', gap: 8 }}
        >
          <MPIcon icon={ICONS.info} size="1.2em" />
          Renewal is automatic.
        </p>
      </div>
    </div>
  );
}
dart
import 'package:flutter/widgets.dart';
import 'package:material_plus_ui/material_plus_ui.dart';

import 'package:material_plus_ui_example/demos/glyphs_display.dart';

class IconColors extends StatelessWidget {
  const IconColors({super.key});

  @override
  Widget build(BuildContext context) {
    final MPThemeData theme = MPTheme.of(context);
    final MPColorScheme colors = theme.colors;
    final double caption = theme.typescale.bodySmall.size;

    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      mainAxisSize: MainAxisSize.min,
      spacing: 24,
      children: <Widget>[
        // A colour named outright. Any colour works, including one of the
        // scheme's own roles, which is what keeps it right in both schemes
        // without the demo knowing which one it is in.
        Wrap(
          spacing: 24,
          runSpacing: 24,
          crossAxisAlignment: WrapCrossAlignment.center,
          children: <Widget>[
            MPIcon(icon: const InfoGlyph(), size: 24, color: colors.primary, label: 'Info'),
            MPIcon(icon: const ErrorGlyph(), size: 24, color: colors.error, label: 'Failed'),
            MPIcon(
              icon: const WarningGlyph(),
              size: 24,
              color: colors.onSurfaceVariant,
              label: 'Careful',
            ),
            const MPIcon(icon: SuccessGlyph(), size: 24, color: Color(0xFF2E7D32), label: 'Done'),
          ],
        ),

        // No colour at all. The icon takes whatever the surrounding text is,
        // which is why both of these come out right without being told.
        Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          mainAxisSize: MainAxisSize.min,
          spacing: 12,
          children: <Widget>[
            _Line(
              color: colors.error,
              icon: MPIcon(icon: const WarningGlyph(), size: caption * 1.2),
              text: 'This certificate expires in three days.',
            ),
            _Line(
              color: colors.onSurfaceVariant,
              icon: MPIcon(icon: const InfoGlyph(), size: caption * 1.2),
              text: 'Renewal is automatic.',
            ),
          ],
        ),
      ],
    );
  }
}

/// A caption in one colour, with an icon that inherits it.
class _Line extends StatelessWidget {
  const _Line({required this.color, required this.icon, required this.text});

  final Color color;
  final Widget icon;
  final String text;

  @override
  Widget build(BuildContext context) {
    final MPThemeData theme = MPTheme.of(context);

    return DefaultTextStyle.merge(
      style: theme.typescale.bodySmall.style(color),
      child: IconTheme.merge(
        data: IconThemeData(color: color),
        child: Row(
          mainAxisSize: MainAxisSize.min,
          spacing: 8,
          children: <Widget>[
            icon,
            Flexible(child: Text(text)),
          ],
        ),
      ),
    );
  }
}

색을 주지 않았을 때도 글리프에는 currentColor를 넘깁니다. 자체 기본값이 고정 색인 세트라도 놓인 자리의 텍스트를 따라가게 하기 위해서입니다.

label ​

label이 없으면 아이콘은 접근성 트리에서 빠집니다. 대부분의 아이콘은 이미 같은 말을 하는 텍스트 옆에 놓이고, 둘 다 읽어 주는 것은 하나만 읽어 주는 것보다 나쁘기 때문에 이쪽이 기본값입니다.

tsx
// 옆의 텍스트가 이미 "삭제"라고 말하고 있습니다.
<Button startIcon={<MPIcon icon={ICONS.close} />}>삭제</Button>

// 글리프뿐이므로 이름이 필요합니다.
<MPIcon icon={ICONS.close} label="닫기" />

label이 있으면 박스가 그 이름을 가진 role="img"이 됩니다.

dart
// 옆의 텍스트가 이미 "삭제"라고 말하고 있습니다.
MPButton(onPressed: delete, startIcon: const MPIcon(icon: CloseGlyph()), child: const Text('삭제'))

// 글리프뿐이므로 이름이 필요합니다.
const MPIcon(icon: CloseGlyph(), label: '닫기')

label이 있으면 그 이름을 가진 이미지 노드가 되고, 없으면 ExcludeSemantics로 감쌉니다. 버튼 전체가 아이콘 하나라면 아이콘은 버튼 안에 두고, 이름은 버튼의 semanticLabel에 줍니다.

아이콘 주변 여백은 박스에 줍니다 ​

글리프는 MPIcon이 그리는 박스를 가득 채웁니다. 그래서 margin은 안쪽 그림이 아니라 그 박스에 주어야 합니다. 이 컴포넌트가 그리는 모든 박스에는 .mp-icon이 붙어 있고, 클래스는 바로 이럴 때 쓰라고 있습니다.

css
.toolbar .mp-icon {
  margin-inline-end: 5px;
} /* 박스 */

.toolbar svg {
  margin-inline-end: 5px;
} /* 그림 */

두 번째 규칙은 Material UI에서 넘어올 때 남는 형태입니다. 거기서는 SvgIcon이 곧 margin을 주는 대상이었습니다. 여기서는 이미 박스를 가득 채운 flex 항목에 margin이 붙으므로 들어갈 자리가 없고, 그대로 눈에 보이게 넘칩니다. 의도한 동작입니다. 예전에는 그 차이를 글리프에서 빼 갔고, size={16}인 아이콘이 11×16으로 그려지면서 그저 한 치수 작아 보이기만 했습니다.

함께 들어 있는 아이콘 세트 ​

lucide-react는 이 패키지의 dependency이고, 라이브러리 자체 컴포넌트가 그리는 모든 글리프는 src/constants/icons.ts 한 파일에 이름이 붙어 있습니다. 꺼내 쓰는 방법은 두 가지입니다.

tsx
import { ICONS, SearchIcon } from 'material-plus-ui';

<MPIcon icon={ICONS.search} />     // 역할 이름으로
<MPIcon icon={SearchIcon} />       // named import로

키는 컴포넌트가 요구하는 역할(visibility)이지, lucide가 마침 제공하는 그림 이름(Eye)이 아닙니다. 컴포넌트는 개념을 요구하므로, 그 뒤의 그림은 컴포넌트를 건드리지 않고 바꿀 수 있습니다.

어느 쪽을 쓸지

ICONS는 객체 리터럴이라 번들러가 속성 단위로 tree-shaking할 수 없습니다. 즉, 이것을 import하면 테이블의 모든 글리프가 딸려 옵니다. 한두 개만 필요하면 named import를, 이름으로 조회하는 레지스트리가 필요하면 ICONS를 쓰세요.

이 세트에만 묶여 있는 것은 아닙니다. MPIcon은 아이콘 컴포넌트 모양을 한 것이면 무엇이든 받으므로 react-icons, @material-symbols, 다른 머터리얼 아이콘 패키지, 직접 만든 SVG 모두 wrapper 없이 그대로 동작합니다.

React 빌드와 다른 점 ​

ReactFlutter이유
icon에 컴포넌트나 엘리먼트IconData나 위젯Flutter에서 아이콘이 가지는 두 형태입니다. 아이콘 폰트의 글리프이거나 위젯입니다.
CSS 길이로 된 sizedouble?CSS 길이가 없습니다. 글자를 따라가야 하면 글자 크기를 읽어서 넘깁니다.
CSS 색상으로 된 colorColor?Color로 받고, null이면 IconTheme으로 이어받습니다.
strokeWidth—위젯은 스스로 그리므로 바깥에서 선 굵기를 넘길 수 없습니다. 가변 아이콘 폰트의 굵기는 IconThemeData.weight가 맡습니다.
center—Center나 Align으로 감쌉니다. 그리드 트랙 안의 배치는 부모가 정합니다.
ICONS와 이름 붙은 글리프 export—Flutter 패키지에는 아이콘 세트가 들어 있지 않습니다. Flutter에는 Material 밖의 아이콘 세트가 없고, 이 패키지는 Material을 가져오지 않습니다. 미리보기의 글리프는 갤러리가 직접 그렸고, 앱도 자기가 고른 세트로 똑같이 하면 됩니다.
className, style, ref, 속성 전달—넘길 클래스 목록, style 속성, 엘리먼트가 없습니다.
