MPSpoiler ​

누군가 요청하기 전까지 가려 두는 내용입니다. 반전, 연봉 범위, 경고가 붙은 사진 — 형태로는 보이지만 실수로는 읽히지 않습니다.

ReactFlutter
tsx
import { MPSpoiler } from 'material-plus-ui';

<MPSpoiler reversible>그 사람은 처음부터 그의 여동생이었습니다.</MPSpoiler>;
dart
import 'package:material_plus_ui/material_plus_ui.dart';

const MPSpoiler(reversible: true, child: Text('그 사람은 처음부터 그의 여동생이었습니다.'));

덮개는 display: none이 아니라 블러입니다 ​

그게 요점의 전부입니다. 읽는 사람은 거기에 무언가가 있다는 것과 그것이 대략 얼마만큼인지를 볼 수 있고, maxHeight가 있으면 잘려 있다는 것도 압니다. 할 수 없는 것은 실수로 읽는 일뿐입니다.

다만 블러만으로는 덮개가 되지 않습니다. 문단을 흩어 놓기는 하지만 색과 리듬은 남고, 10px로 흐려진 사진도 여전히 알아볼 수 있는 얼굴 사진입니다. 그래서 그 위에 페이지 자신의 surface 역할을 섞은 막이 한 겹 올라갑니다. 두 가지가 한꺼번에 정리됩니다. 내용은 자기 색들이 뭉개진 얼룩이 되고, 버튼은 우연히 그 아래 있던 무언가가 아니라 딛고 설 자리를 얻습니다.

컨테이너 역할이 아니라 surface인 이유는, 이 막이 시트가 아니라 페이지를 대신하고 있기 때문입니다. MPOverlay의 solid 톤이 읽는 것과 같은 역할이고, 이유도 같습니다.

내용이 inert인 이유 ​

가려져 있는 동안 내용은 탭으로 닿지 않고, 스크린 리더가 읽지 않으며, 페이지를 가로지르는 드래그로 선택되지도 않습니다.

셋 다 중요합니다. Ctrl-A로 뚫리는 스포일러는 스포일러가 아니고, aria-hidden만으로는 스크린 리더가 없다고 들은 링크로 키보드 사용자가 탭해 들어가게 됩니다. 속성 하나가 그 전부를 처리합니다.

가려져 있는 동안 내용은 포커스 순서와 시맨틱 트리와 포인터에서 빠지고, SelectionArea나 SelectableRegion 안에서는 선택되지도 않습니다.

넷 다 중요합니다. 전체 선택으로 복사되어 나가는 스포일러는 스포일러가 아니고, 시맨틱 트리에서만 빼면 스크린 리더가 없다고 들은 링크로 키보드 사용자가 탭해 들어가게 됩니다. Flutter에는 이 전부를 처리하는 속성 하나가 없으므로 스포일러가 하나씩 빼고, 내용은 다시 돌아올 때 자기 상태를 그대로 가집니다.

상자는 움직이지 않습니다 ​

스포일러를 여는 것이 페이지를 밀어내지 않습니다. 예전에는 두 가지가 상자를 움직였고, 둘 다 옷만 다른 같은 실수입니다. 한쪽 상태에서만 그려지는 것이 있는데, 그것이 없는 쪽 상태가 그 자리 값을 치르지 않는 것입니다.

reversible 시트의 되돌아가는 길은 처음부터 자리를 잡고 있고, 시트가 가려진 동안에는 보이지 않을 뿐입니다. React에서는 invisible과 inert, Flutter에서는 크기를 지키는 Visibility와 ExcludeFocus라서 접근성 트리에서도 탭 순서에서도 빠져 있습니다. 가려진 내용이 그런 것과 똑같습니다. 그 위를 덮개가 덮고 있으므로 들여다볼 빈 공간도 없습니다. 이것이 없을 때는 독자가 안쪽 버튼을 누르는 순간 시트가 버튼 하나와 패딩 한 칸만큼 자랐고, 되돌아갈 때 다시 줄었습니다.

덮개는 그 위에 얹은 absolute 상자가 아니라 모든 행을 span하는 grid 항목입니다. 이것은 위치가 아니라 크기에 대한 결정입니다. Flutter에서는 같은 이유로 내용과 같은 Stack의 위치 없는 자식입니다. 절대 위치 요소는 컨테이너 높이에 아무것도 기여하지 않으므로, 짧은 한 줄을 두 줄짜리 안내문과 버튼으로 덮은 시트는 자기 덮개보다 작았습니다. 그리고 시트는 clip하므로, 독자에게 누르라고 내미는 그 버튼이 아래쪽 가장자리에서 잘려 나갔습니다.

오버레이가 있는 다른 모든 것에 적용되는 일반 규칙: 오버레이가 자기가 덮는 것보다 커질 수 있으면 그것은 absolute가 아니라 항목입니다. 그리고 한쪽 상태에서만 존재하는 컨트롤은 다른 쪽에서 자리를 예약해야 합니다.

문구는 번역되어 있습니다 ​

덮개는 이 라이브러리에서 컴포넌트 자신의 단어가 읽히기만 하는 것이 아니라 그려지는 유일한 자리입니다. 그래서 영어 기본값을 가진 prop이 아니라 메시지 표에서 옵니다.

tsx
<MPSpoiler locale="ko">가려진 내용</MPSpoiler>
// "보기", "실수로 읽지 않도록 가려 두었습니다"
dart
const MPSpoiler(locale: 'ko', child: Text('가려진 내용'));
// "보기", "실수로 읽지 않도록 가려 두었습니다"

locale을 생략하면 가장 가까운 MPLocaleProvider를 따릅니다. label, hideLabel, description은 기본 문구가 맞는 문구가 아닐 때를 위한 것입니다. 채용 공고의 스포일러가 원하는 말은 "실수로 읽지 않도록 가려 두었습니다"가 아니라 "연봉 범위"입니다.

예시 ​

ReactFlutter
tsx
import { MPSpoiler, MPTypography } from 'material-plus-ui';

/**
 * `maxHeight` clamps the **covered** box only.
 *
 * Set it for something long enough that a page of blurred content would be a
 * page of nothing. Revealing releases the clamp and the content takes whatever
 * height it needs — revealing something and leaving it in a box with a scrollbar
 * is answering the wrong question.
 *
 * `padded={false}` is for content that should reach the edges. The sheet's own
 * corners still crop it.
 */
export default function SpoilerClamped() {
  return (
    <div style={{ display: 'grid', gap: 16, width: '100%', maxWidth: 460 }}>
      <MPSpoiler maxHeight={96} blur={6} reversible label="Read the ending">
        <MPTypography level="body">
          The train was late, which is how she came to be standing on the platform when the letter
          arrived. It had been posted four years earlier, from an address that no longer existed, by
          a man who had signed it with her own surname. She read it twice on the platform and a
          third time on the train, and by the time she reached the coast she had decided what to do
          about it.
        </MPTypography>
      </MPSpoiler>

      <MPSpoiler padded={false} description="Contains flashing images">
        <img
          src="/samples/photos/thumbs/rainy-city-crosswalk-reflections.webp"
          alt="A city crossing at night, headlights running down the wet road"
          style={{ display: 'block', width: '100%', height: 120, objectFit: 'cover' }}
        />
      </MPSpoiler>
    </div>
  );
}
dart
import 'package:flutter/widgets.dart';
import 'package:material_plus_ui/material_plus_ui.dart';

/// `maxHeight` clamps the **covered** box only.
///
/// Set it for something long enough that a page of blurred content would be a
/// page of nothing. Revealing releases the clamp and the content takes whatever
/// height it needs: revealing something and leaving it in a box with a
/// scrollbar is answering the wrong question.
///
/// `padded: false` is for content that should reach the edges. The sheet's own
/// corners still crop it.
class SpoilerClamped extends StatelessWidget {
  const SpoilerClamped({super.key});

  @override
  Widget build(BuildContext context) {
    return ConstrainedBox(
      constraints: const BoxConstraints(maxWidth: 460),
      child: const Column(
        crossAxisAlignment: CrossAxisAlignment.stretch,
        spacing: 16,
        children: <Widget>[
          MPSpoiler(
            maxHeight: 96,
            blur: 6,
            reversible: true,
            label: Text('Read the ending'),
            child: MPTypography(
              'The train was late, which is how she came to be standing on the platform when the '
              'letter arrived. It had been posted four years earlier, from an address that no '
              'longer existed, by a man who had signed it with her own surname. She read it twice '
              'on the platform and a third time on the train, and by the time she reached the '
              'coast she had decided what to do about it.',
              level: MPTypographyLevel.body,
            ),
          ),
          MPSpoiler(
            padded: false,
            description: Text('Contains flashing images'),
            child: Image(
              image: NetworkImage('/samples/photos/thumbs/rainy-city-crosswalk-reflections.webp'),
              width: double.infinity,
              height: 120,
              fit: BoxFit.cover,
              semanticLabel: 'A city crossing at night, headlights running down the wet road',
            ),
          ),
        ],
      ),
    );
  }
}

maxHeight ​

가려진 상자에만 걸립니다. 흐려진 내용이 화면을 가득 채우면 아무것도 없는 화면이 되어 버릴 만큼 긴 내용에 지정하세요.

열면 제한이 풀리고 내용은 필요한 높이를 그대로 가집니다. 무언가를 보여 주면서 스크롤바 달린 상자에 남겨 두는 건 엉뚱한 질문에 답하는 일입니다.

reversible ​

한 번 열린 뒤 내용 아래에 다시 가리는 버튼이 나타납니다. 기본은 꺼짐입니다. 대부분의 스포일러는 한 번 읽히고 그대로 남습니다.

그 줄은 처음부터 그려져 가려진 동안에도 자리를 지킵니다. 그래서 이 옵션을 켜면 가려진 시트가 그만큼 높아지고, 여는 순간에는 상자가 움직이지 않습니다. 상자는 움직이지 않습니다를 보세요.

padded ​

가장자리까지 닿아야 하는 내용 — 사진, 영상 — 에는 꺼 두세요. 시트 자신의 모서리는 여전히 내용을 잘라내고, 덮개도 상자 전체를 채웁니다.

action ​

누름이 아닌 다른 것 — 결제, 연령 확인, 권한 — 으로 열리는 스포일러를 위해 공개 버튼 전체를 대체합니다.

tsx
<MPSpoiler revealed={unlocked} action={<MPButton onClick={verify}>연령 확인</MPButton>}>
  …
</MPSpoiler>
dart
MPSpoiler(
  revealed: unlocked,
  action: MPButton(onPressed: verify, child: const Text('연령 확인')),
  child: content,
);

대체한 컨트롤은 직접 연결해야 합니다. revealed를 넘기고 자기 상태로 구동하세요. 기본 버튼의 변화도 받아야 한다면 onRevealedChange를 함께 넘깁니다. 이미 있는 버튼의 문구만 바꾸고 싶다면 훨씬 흔한 그 경우를 위한 prop이 label입니다.

접근성 ​

  • 공개 버튼은 aria-expanded와 내용을 가리키는 aria-controls를 가진 진짜 MPButton입니다. 스크린 리더는 그 뒤에 무언가가 있고 지금은 닫혀 있다는 것을 듣습니다.
  • 가려진 내용은 inert이므로 탭으로도, 스크린 리더로도, 선택으로도 그 안의 무엇에도 닿지 않습니다.
  • 버튼 위의 안내는 평범한 텍스트라서, 읽는 사람은 결정하기 전에 무엇이 왜 가려져 있는지 읽을 수 있습니다.
  • 블러는 filter 전환이고 prefers-reduced-motion에서 사라집니다. 덮개 자체는 애니메이션되지 않는데, 천천히 사라지는 스포일러는 사라지는 동안 읽히는 스포일러이기 때문입니다.
  • 공개 버튼은 접혀 있다고 말하는 진짜 MPButton이고, 가리기 버튼은 펼쳐져 있다고 말합니다. 스크린 리더는 덮개 뒤에 무언가가 있다는 것과 지금 보이는지를 듣습니다.
  • 가려진 동안 내용은 포커스 순서, 시맨틱 트리, 포인터, 선택 어디에서도 닿지 않습니다.
  • 버튼 위의 안내는 평범한 텍스트라서, 읽는 사람은 결정하기 전에 무엇이 왜 가려져 있는지 읽을 수 있습니다.
  • 블러는 짧은 시간에 걸쳐 걷히고 MediaQuery.disableAnimations가 켜져 있으면 바로 사라집니다. 덮개 자체는 애니메이션되지 않는데, 천천히 사라지는 스포일러는 사라지는 동안 읽히는 스포일러이기 때문입니다.

React 빌드와 다른 점 ​

ReactFlutter이유
childrenchildFlutter의 이름입니다.
defaultRevealedinitialRevealed비제어 위젯의 시작 상태를 부르는 Flutter의 이름입니다.
description={false}showDescription: falseDart에는 null도 위젯도 아닌 값이 없습니다.
maxHeight가 숫자나 아무 CSS 길이를 받습니다maxHeight는 논리 픽셀입니다CSS 길이가 없습니다.
버튼의 aria-controls—Flutter의 시맨틱에는 한 노드가 다른 노드를 가리키는 방법이 없습니다. 내용이 보이는지는 버튼이 여전히 말합니다.
내용이 inert입니다포커스 순서, 시맨틱 트리, 포인터, 선택에서 하나씩 뺍니다넷을 한꺼번에 처리하는 속성이 Flutter에는 없습니다.
className, style, 네이티브 속성—넘겨줄 곳이 없습니다.
